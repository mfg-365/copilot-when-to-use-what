✅ Reach for Chat when…

  • You need a quick answer, fact, or explanation
  • You're catching up on emails, chats or meetings
  • You want to draft or refine one thing — an email, a summary, a section
  • You're brainstorming or exploring options interactively
  • You need deep research or data analysis (via the Researcher / Analyst agents)

⛔ Move on when…

  • One request should produce several artifacts → Cowork
  • It's a multi-step process across systems → Cowork
  • It should run on a schedule or while you're away → Scout
  • You're building software → Code
  • It's a repeatable capability for a whole team → Custom agent

Inside Chat

Five modes — pick by intent

Copilot Chat is one surface with distinct modes. Start in Chat, then match the mode to what you're trying to do.

💬

Chat

The default conversation. Ask a question, catch up, or draft one thing — grounded in the web and your Work IQ, with you steering every turn. The other four modes below extend Chat for specific intents.

🔍

Search

Find and synthesize across the web and your organization's content. Best when you need a grounded answer or a pointer to the right document, person or message.

Use for  “What's our latest guidance on X?” · “Find the deck from last quarter's review.”

📓

Notebook

Ground a reusable working set. Pin the sources, notes and files you're actively working with so Copilot reasons over a stable, curated context you return to again and again.

Use for  A long-running project, a research corpus, a recurring analysis you keep refining.

🎨

Create

Generate visual & creative content — images and designed assets — from a prompt, right inside Chat.

Use for  An image for a deck, a concept visual, a quick graphic.

🧩

Agents

Specialized helpers inside Chat — including Microsoft's growing catalog of first-party agents and any custom agents your org publishes. Bring in expertise or actions beyond a general chat turn.

Use for  Deep research, data analysis, or a domain task an agent is built for.

First-party agents in Chat

When a scenario calls for Researcher or Analyst

Two Microsoft first-party agents extend Chat for the heaviest reasoning tasks — but they're only the start. Microsoft ships a growing catalog of first-party agents across Microsoft 365 Copilot, Copilot Studio and Dynamics 365, each on its own release track.

Researcher

Deep, multi-source research

Runs an extended research process across many web and work sources, then synthesizes a structured, cited report. Use it when a single chat answer isn't thorough enough.

Scenario: “Build me a competitive landscape on [topic], pulling from our internal docs and the public web, with sources.”

Analyst

Reason over data

Works through data analysis step by step — interpreting spreadsheets and datasets, running the reasoning, and returning findings you can act on.

Scenario: “Analyze this quarter's usage export, find the patterns, and summarize what changed versus last quarter.”

Where a custom agent may make more sense

If the same research or analysis runs repeatedly against the same sources — and teammates need it too — that recurring scenario is a strong candidate to package as a custom agent with fixed knowledge and guardrails, rather than re-prompting Chat each time. Before building, check the first-party catalog — Microsoft may already ship an agent for the job, including pre-built agents in Dynamics 365 (sales, contact center, customer service, Business Central).

Entitlement matters

Copilot Chat with vs. without a Microsoft 365 Copilot license

Copilot Chat is broadly available; a Microsoft 365 Copilot license unlocks grounding in your work content and Copilot embedded in the Microsoft 365 apps. Knowing which you have changes what Chat can do.

Without a Copilot license
  • Web-grounded chat for general questions, drafting and ideation
  • Enterprise data protection on eligible accounts
  • Access to agents, with some actions metered / pay-as-you-go
With a Copilot license
  • Grounding in your Work IQ — your emails, files, meetings and chats
  • Copilot embedded across Word, Excel, PowerPoint, Outlook and Teams
  • Full access to first-party agents like Researcher and Analyst
  • Higher limits and priority
