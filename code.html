Copilot Code

Natural-language software building, grounded in Work IQ. Describe what you want to build and Code helps you create it — locally or in the cloud, across multiple models, with plugins and connectors to your systems.

When to choose Code

✅ Reach for Code when…

  • The deliverable is software — an app, script, automation, or data pipeline
  • You want to build in natural language but ship real, runnable code
  • You need local or cloud development, with your choice of model
  • The solution should connect to systems via plugins and connectors
  • A business process is best expressed as code rather than a document

⛔ Use something else when…

  • The output is documents or business artifacts → Cowork
  • You just need an answer or a snippet explained → Chat
  • You want an always-on operator, not a build → Scout
  • Non-developers need a reusable tool → Custom agent

Code vs. Cowork

Both are agentic and Work IQ–grounded. The difference is the medium: Cowork produces business artifacts and takes M365 actions; Code produces software. If the answer to “what am I left holding?” is a repo, a script or an app → Code.
