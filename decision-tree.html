One app, one home base

Chat, Cowork, Code and Scout all live inside the Microsoft 365 Copilot app — so stepping up is switching capability, not switching tools. Copilot Chat is broadly available, so it's where the whole organization builds fluency first. Cowork, Code and Scout are typically enabled for a limited set of licensed users and expanded over time — so in practice most people live in Chat and step up to a more autonomous surface as both the need and their access grow.

Inside Chat — which mode?

Search for a company/web fact · Notebook to ground a reusable working set · Create for images & visual content · Researcher agent for deep multi-source research · Analyst agent for data reasoning & analysis.
